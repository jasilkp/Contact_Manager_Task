# Contact Book Application

A simple command-line contact book where you can add, view, search, update and delete contacts. Everything is saved to a text file.

## Features

- Add new contacts (name, phone, email, address)
- View all saved contacts in a table
- Search contacts by name, phone or email
- Update or delete existing contacts
- Phone and email validation
- Data stored in `contacts.txt`

## How to Run

```
python contact_book.py
```

No extra libraries needed, just Python.

## Files

- `contact_book.py` - main program
- `contacts.txt` - data file (auto-created when you add your first contact)
- `README.md` - this file

## How it Works

When you run the program you get a menu with 6 options. Pick a number and follow the prompts. Contacts are saved as `Name | Phone | Email | Address` in the text file, one per line.
